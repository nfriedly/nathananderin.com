Uses USB 3.0 connectors, but has a USB 2.0 chip inside, so it only operates at USB 2.0 speeds - about 40MB/s. Also, it back-feeds 5v into the USB-A male plug when powered via USB-C. I suppose some folks want that for powering a Raspberry Pi zero or the like, but it's not the correct/expected behavior. Finally, there's something wrong with the port nearst the light on mine - a mouse works fine, and a USB drive will appear when plugged in, but when I try to do a speed test with CrystalDiskMark, it freezes. The other ports all work fine and get the ~40MB/s in the screenshot (with a USB SSD that can do 800-900MB/s on a proper USB 3.0 port)
