I ordered this crash pack the other day and while the description and picture already seem to disagree somewhat, the pack I received matched neither:

* 240mAh battery when the description claims 380mAh

* Did not include the 2pcs LED lights that are mentioned in the description

* Did not include the propeller replacement tool shown in the picture

* Did not include replacement rubber feet alluded to in the description ("Material: durable hard plastic and soft rubber." - nothing I received was made of soft rubber, and that would only make sense for the feet.)
