I’m not usually one for an unplanned pregnancy in my romance but this one was so good and I picked it up not knowing that it would be part of the plot. This book was so, so good. If this is a spoiler, I’m not sorry, I want to shout it from the roof tops that there is no third act break up.  Once it’s happy it stays happy. I want more endings like this one.  I was thrilled with the representation of two disabled people finding love. More of all of this please.
