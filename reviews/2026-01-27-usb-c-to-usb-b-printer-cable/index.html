Good USB Type-B to Type-C cable

USB-C to USB-B printer cable Review

by Nathan Friedly

Arzweyk USB B to USB C Printer Cable Cord Compatible with HP OfficeJet Pro 8125e, 8135e, 9730e, 9135e, 9125e, 8139e, DeskJet 4227e, 2855e, 2827e, Smart Tank 5000, 5101 for Laptops, MacBooks (6.6FT)

Price: $11.99

Amazon

Ordered on: 2026-01-18

Reviewed on: 2026-01-27

Works perfect to let my MacBook print on my printer! It used to be able to print and scan wirelessly, but one MacOS update broke printing and another broke scanning. So then I was stuck using a cable + dongle, which worked but was annoying. Having a single cable is simpler and more convenient.

The cable is fairly thin and flexible, but feels sturdy enough. 2 meters is a decent length - enough that you don't need to have your computer right next to the printer.

Just for kicks, I tried it with my phone, a Pixel 9 Pro, but apparently Android doesn't support USB printers (on the other hand, it can print wirelessly still, so no big deal.) Same results with my iPad.

Because it's a standard USB cable, it should work with any old USB Type-B device you happen to have: camera, 3D printer, Arduino, hard drive dock, etc. It's only USB 2.0 speed, but that's fine for a printer and most other use cases.
